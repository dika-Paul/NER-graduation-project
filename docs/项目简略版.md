# 项目简略版

## 一、项目名称

面向材料科学文献的命名实体识别与大模型辅助伪标注迭代训练系统

## 二、项目简介

本项目围绕材料科学英文文献中的命名实体识别任务展开，目标是从论文标题、摘要等文本中自动识别材料名称、性能、表征方法、合成方法、应用场景等领域实体。项目在传统深度学习序列标注模型和预训练语言模型的基础上，引入大语言模型辅助伪标注机制，用于扩充训练样本并提升低标注数据场景下的实体抽取能力。

## 三、主要功能

- 将 MatScholar 领域数据转换为 BIO 序列标注格式。
- 实现并训练多种 NER 模型，包括 BiLSTM-CRF、BERT-Softmax、BERT-BiLSTM-CRF 和 MatSciBERT-Softmax。
- 使用 precision、recall、F1 和 loss 对模型效果进行评估。
- 构建基于 LangGraph 的迭代训练流程，支持模型预测、大模型预测、差异度计算、决策筛选和伪标注数据追加。
- 支持从 OpenAlex Excel 文献池中批量读取论文标题和摘要，并转换为句子级样本参与后续训练。

## 四、实体类别

项目采用材料领域常见实体标签：

- MAT：材料、化合物、复合材料、掺杂元素等。
- SPL：晶相、对称性、结构相等。
- DSC：材料描述、形貌、结构、样品类型等。
- PRO：材料性质、性能指标等。
- APL：应用场景、器件或功能目标。
- SMT：合成方法、制备路线、处理工艺。
- CMT：表征方法、测试技术、实验仪器。

## 七、项目成果

项目完成了材料文献命名实体识别的模型训练、评估和伪标注迭代流程设计。通过对不同模型结构的实现和对比，为材料科学文献自动信息抽取提供了可复现实验基础，也为后续构建材料知识图谱、文献自动分析系统提供了数据处理入口。
