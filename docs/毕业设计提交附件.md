# 毕业设计提交附件说明

## 一、基本信息

- 项目名称：面向材料科学文献的命名实体识别与大模型辅助伪标注迭代训练系统
- 项目目录：NRE_project
- 主要任务：材料领域英文文献命名实体识别、模型训练评估、伪标注样本扩充
- 开发语言：Python
- 提交日期：2026 年 6 月 2 日

## 二、项目背景

材料科学文献中包含大量材料名称、制备方法、性能指标、表征方法和应用场景等关键信息。人工阅读和标注文献成本较高，而命名实体识别可以从文本中自动抽取结构化信息，为后续材料知识图谱构建、文献检索、实验路线分析和材料性能预测提供基础数据。

本项目以材料科学文献为研究对象，完成领域命名实体识别模型的实现、训练、评估与增强流程设计。项目在已有人工标注数据的基础上，引入大语言模型辅助伪标注策略，用模型预测结果与大模型抽取结果进行一致性判断，从而筛选高置信样本加入训练集，实现迭代式数据扩充。

## 三、项目目标

- 构建材料领域 NER 数据处理流程，将原始标注数据转换为 BIO 格式。
- 实现多类序列标注模型，并完成训练和验证。
- 建立统一评估函数，对不同模型输出进行 precision、recall、F1 和 loss 计算。
- 设计大模型辅助伪标注流程，用于低标注数据场景下的样本扩充。
- 支持从外部文献池中批量读取标题和摘要，形成可参与标注筛选的文本样本。

## 四、核心模型

项目包含以下模型实现：

- BiLSTM-CRF：使用词嵌入、双向 LSTM 和 CRF 完成传统序列标注。
- BERT-Softmax：使用 BERT 编码器和线性分类层完成 token 级分类。
- BERT-BiLSTM-CRF：将 BERT 表征、BiLSTM 上下文建模和 CRF 解码结合，增强标签序列约束。
- MatSciBERT-Softmax：使用材料科学领域预训练模型 MatSciBERT 作为编码器，提升领域文本适配能力。

## 五、大模型辅助迭代流程

项目在 `graph/` 目录中实现基于 LangGraph 的伪标注迭代训练流程，主要步骤如下：

1. 初始化训练集、验证集和未标注文献池。
2. 训练当前 NER 模型并保存本轮最佳 checkpoint。
3. 使用当前最佳模型对未标注样本进行 BIO 预测。
4. 调用主大模型对同一批样本进行 span 格式实体抽取。
5. 将 NER 结果和大模型结果转换为实体字典，计算编辑距离差异比例。
6. 当差异较大时调用 judge 大模型复核。
7. 根据 NER、主大模型和 judge 大模型之间的一致性进行决策。
8. 接受高置信 NER 结果或大模型共识结果，并将其转换为 BIO 格式追加进训练集。
9. 进入下一轮训练，直到达到迭代次数或文献池处理完毕。

## 七、数据与标签

本项目使用 BIO 格式表示实体边界和实体类型。每个 token 对应一个标签，实体起始位置使用 `B-实体类型`，实体内部位置使用 `I-实体类型`，非实体位置使用 `O`。

实体类型包括：

- MAT：材料、化学式、化合物、复合材料等。
- SPL：晶相、结构相、对称性标签等。
- DSC：描述性实体，如形貌、结构、样品形态等。
- PRO：性能、性质、物理化学属性等。
- APL：应用、器件、功能目标等。
- SMT：合成、制备、加工方法等。
- CMT：表征、测试、测量方法等。

## 八、运行与复现说明

1. 准备 Python 环境，并安装 PyTorch、Transformers、torchcrf、seqeval、rapidfuzz、LangChain、LangGraph 等依赖。
2. 将数据集放入 `data/` 目录。由于数据文件和模型权重体积较大，仓库默认不提交 `data/`、`embeddings/` 和 `*.pt` 文件。
3. 如需转换 MatScholar 数据，可运行 `utils/convert_matscholar_to_bio.py`。
4. 如需训练单个模型，可打开 `train/` 目录下对应 Notebook。
5. 如需执行大模型辅助迭代流程，可使用 `graph/graph.py` 中的 `build_train_graph()` 或 `build_add_train_graph()` 构建流程，并提供模型类型、LLM、judge LLM、数据路径等上下文参数。
6. 训练和运行过程中产生的模型权重、缓存和输出文件不作为源码提交内容，可按需要单独保存。

## 十、项目总结

本项目完成了面向材料科学文献的命名实体识别系统设计与实现，覆盖数据处理、模型训练、模型评估和大模型辅助伪标注流程。项目既包含可对比的基础模型，也包含面向低标注数据场景的自动扩充策略，能够为材料文献结构化抽取和后续知识图谱构建提供支持。
